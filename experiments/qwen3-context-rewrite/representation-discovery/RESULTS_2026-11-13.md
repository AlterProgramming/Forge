# Representation geometry unlocks learned relational composition in frozen Qwen3-0.6B

**Executed research report · 13 November 2026 · CPU only**

## Abstract

A frozen Qwen3-0.6B model supplied contextual sentence vectors to a 294K-parameter external controller. On the original Facebook bAbI Task 19 Path Finding test, an anonymous six-node differentiable graph composer trained **only on final question-answer pairs** improved from **411/1,000** correct using unmodified Qwen sentence vectors to **806/1,000** using *unsupervised whitening* of the same vectors, at the same random seed and with unchanged learning and model parameters. The paired gain is **+39.5 percentage points**, a 95% story-bootstrap interval **[35.7, 43.2] pp** and exact paired McNemar **p=1.52e-76**. Average pairwise cosine among the original 150 Qwen sentence embeddings was **0.9139**, indicating high anisotropy on this fixed vocabulary. Centering alone reached **535/1,000**, whereas randomly permuting Qwen embeddings across sentences reached **83/1,000**.

The controller discovered **anonymous node addresses** and learned to bind relations to them from outcome supervision. With eight (not exactly six) unnamed addresses, it achieved **869/1,000** using a fixed compass inverse. Replacing that fixed inverse with a learned 4×4 matrix produced **804/1,000** and **853/1,000** across two seeds. The learned matrix concentrated ~0.92 probability on the correct reverse for each cardinal direction. A matched eight-address control without reverse computation scored **256/1,000**. A consistent permutation of all eight latent address identities left predictions unchanged (804/1,000, max absolute logit error 9.54e-7).

A tougher lexical generalization test removed 12 of 120 relationship sentence types entirely from training, trained on the remaining 5,311 stories, and fitted whitening **only on observed training sentence types**. Among the 169 original official test questions for which a withheld sentence was one of the benchmark-annotated necessary supporting facts, whitened-Qwen features scored **74/169** versus **13/169** for fixed random sentence identifiers (same seed, paired p=7.78e-13); a second seed scored **70/169** versus **14/169** (p=5.77e-12). This supports pretrained semantic transfer beyond lookup-table memorization.

**The claim is limited:** the two-edge path-composition algebra and output direction alphabet were architectural priors, and the original Qwen weights did not learn to rewrite their own internal activations. A handwritten exact classical solver scored **1,000/1,000**. Cross-task testing found **no universal whitening benefit**: on the independent bAbI Task 2 with an ordinary GRU state, whitening *reduced* official test accuracy from 418/1,000 to 370/1,000 under a matched training protocol.

## 1. Benchmark and data provenance

- **Task:** Facebook bAbI `tasks_1-20_v1-2` Task 19 (`qa19_path-finding`) English **en-10k**. Exact original training and test files retrieved via GitHub Actions from `https://s3.amazonaws.com/text-datasets/babi_tasks_1-20_v1-2.tar.gz`.
- **Official split:** 10,000 train stories/QA, 1,000 official held-out test stories/QA. For tuning, 9,000 of official train stories were used to fit parameters and 1,000 disjoint stories to select epochs. The official test labels were not used during model training or checkpoint selection.
- **Input:** five spatial relation sentences and one query per story. Answers are pairs of directions such as `s,e`; they are *not verbatim strings present in a single evidence sentence*.
- **Frozen encoder:** official `Qwen/Qwen3-0.6B`; final hidden state for each of the **120 unique relation sentences and 30 unique question strings** was computed once locally. Qwen parameters remained unchanged throughout. Qwen feature extraction including model load took ~6.1 seconds for 150 sentence types in this CPU environment. Feature cache is bundled.
- **Supervision:** Only correct final path labels. No annotated supporting-fact indices, intermediate graph edges, entity-slot labels, room-to-slot mappings, or transition labels entered controller training.
- **Mathematical inductive biases:** the answer is a two-edge path; four known directional output codes; relations have reversible edges; the controller uses a differentiable graph workspace with either six or eight **unnamed** node addresses. These priors constrain the candidate program space substantially. The model does not discover them freely.

## 2. Computational mechanism

For each event embedding \(e\), the model produces soft node-address distributions \(a(e), b(e)\in \Delta^{K-1}\) and a directional distribution \(r(e)\in\Delta^3\). It updates four continuous matrices \(G_d\in\mathbb R^{K\times K}\) by adding a soft outer-product binding for the relation and its reverse. When reverse direction semantics are not provided, a trainable matrix \(R\) generates \(\tilde r(e)=r(e)R\) from final-answer supervision.

The query produces soft source/target node vectors \(u(q), v(q)\). The answer distribution is derived from **two successive latent matrix compositions**:

\[
\operatorname{score}(d_1,d_2\mid q,E)=\log\big(u(q)^\top G_{d_1}G_{d_2}v(q)+10^{-7}\big).
\]

This is a *non-text, state-dependent relational computation* performed by the controller. It is not an ordinary text summary. It is also not end-to-end Qwen hidden/KV self-rewriting: pretrained Qwen supplies representations, and the external trained module constructs, updates and reads the graph.

## 3. Representation-only coordinate intervention

For 150 distinct frozen Qwen sentence vectors \(F\), unsupervised centering and SVD give \(F-\mu=U\Sigma V^\top\). Replacing the training vectors by \(8UV^\top\) sphericalizes their geometry without using labels or changing pretrained weights. On a held-out sentence \(x\), the mapping is fitted only from the training sentence vectors and then applied as \(8(x-\mu)V_r\Sigma_r^{-1}V_r^\top\). This is a linear transform on the training span, not additional supervision.

| Input condition (anonymous 6-node model, seed 11819) | Official Task 19 test |
|---|---:|
| Original frozen Qwen3 | **411/1,000** |
| Qwen vectors, centered only | **535/1,000** |
| Same Qwen vectors, whitened | **806/1,000** |
| Qwen vectors randomly reassigned to different sentences | **83/1,000** |
| Fixed random vectors uniquely identifying each sentence | **930/1,000** |

Robustness: Qwen original scored **368/1,000** at seed 11820 and **467/1,000** at seed 11821; Qwen whitened scored **776/1,000** at seed 11820; fixed random IDs scored **792/1,000** at seed 11820. The randomly initialized training system has material seed variance. **Random IDs are not a semantic generalization result:** all 150 original sentence types already occur in the official training vocabulary.

The classical exact graph shortest-path baseline solved **1,000/1,000**, with a recorded solve-only CPU time of ~0.015 seconds for 1,000 questions, excluding data parsing. The neural method is not faster or more accurate than this baseline; its role is to test learning the representation/operator from answers.

## 4. Sentence-type withholding and necessary-fact evaluation

From the original official Task 19 *training* event vocabulary, select twelve complete relation strings with fixed seed 1922. Remove every training and validation story containing any selected sentence. Result: **5,311 training** and **608 validation** stories. The untouched official 1,000-question test contains **425** stories mentioning a withheld sentence; of those, only **169** require such a sentence for the correct answer according to the benchmark's original support metadata. Those metadata were used **only to stratify post-training evaluation**, never for training, loss construction, feature whitening or checkpoint selection.

| Representation / method (K=6, seed 11819) | Official test total | Necessary unseen sentences |
|---|---:|---:|
| Original Qwen vectors | 90/1,000 | 12/169 |
| Fixed random sentence IDs | 844/1,000 | 13/169 |
| **Train-vocabulary-only whitened Qwen** | **885/1,000** | **74/169** |

For this necessary-unseen subset, whitened Qwen versus random IDs gives **+36.09 pp**, story-bootstrap 95% CI **[27.22,44.97] pp**, paired exact p=**7.78e-13**. At seed 11820, the same comparison is 70/169 versus 14/169 (paired p=**5.77e-12**). A random identifier cannot express any shared semantics for a truly unseen sentence, though it often answers questions where the unseen sentence is merely an irrelevant distractor. This is why the **necessary-fact** split matters.

The unmodified-Qwen run trained poorly in this more difficult setting, including on seen sentences, so 12/169 is not an estimate of an intrinsic pretrained-model ceiling. Whitening and the learning system jointly explain the observed improvement.

## 5. Learned computational inverse and surplus anonymous slots

On the *withheld-sentence* version of Task 19:

| Eight-slot continuous graph, seed 11819 | Official test | Necessary unseen sentences |
|---|---:|---:|
| Without reverse-edge computation | **256/1,000** | 37/169 |
| Reverse map learned from final answers | **804/1,000** | 41/169 |
| Reverse mapping given as known operator | **869/1,000** | 74/169 |

The learned-inverse eight-slot model also scored **853/1,000** at seed 11820, with 57/169 necessary-unseen cases correct. Its 4×4 soft inverse mapping at seed 11819 assigned:

| Forward direction | Highest-probability inverse | Probability |
|---|---|---:|
| north | south | 0.921 |
| south | north | 0.918 |
| east | west | 0.923 |
| west | east | 0.917 |

Learned inverse vs no inverse at K=8 is a matched same-seed comparison: **+54.8 pp** on official test, 95% story-bootstrap CI **[51.2,58.3] pp**, paired exact p=**7.01e-128**. The fixed-inverse controller is more accurate, so the learned operation has **not** reached the exact available capability.

To test whether slot indices were functioning as secretly named labels, every occurrence of the eight internal address coordinates in the four endpoint/query heads was permuted consistently. All **804/1,000** test predictions stayed unchanged; maximum absolute logit change was **9.54e-7**. This matches the graph system's theoretical permutation symmetry. It establishes label irrelevance, **not** a proof that its representation is optimal or that no domain prior was supplied.

## 6. Cross-task transfer boundary and earlier shortcut correction

The identical unsupervised whitening transform was applied to the previously investigated **bAbI Task 2 (two-supporting-facts)**, keeping its original ordinary full-stream 128-dimensional GRU architecture and frozen Qwen feature preprocessing. The raw and whitened runs used the same story-disjoint 9,000/1,000 train/validation split, seed and checkpoint selection procedure. On the official 1,000-question test:

| Independent Task 2 recurrent memory | Correct |
|---|---:|
| Original frozen Qwen sentence features | **418/1,000** |
| Whitened Qwen sentence features | **370/1,000** |

Thus geometric whitening can **harm** a different learning architecture and task, even with the same pretrained Qwen backbone. No universal benefit is demonstrated.

Additionally, an earlier Task 2 'oracle selected supporting facts' ablation gave 1,000/1,000 on the two facts. An independent audit showed the ground-truth answer location name was the **only** location word occurring in every selected supporting pair, making that condition solvable by lexical extraction. It was **not** valid evidence of successful two-hop reasoning. The current Task 19 has composite two-direction answers and was selected to avoid that particular shortcut.

## 7. Scientific interpretation and next falsifiable gate

**Established:** Frozen Qwen3 features can support answer-trained discovery of useful anonymous relational addresses and a nontrivial relation-inverse transformation. Unsupervised geometry changes can strongly affect whether a small downstream computation discovers those structures. Pretraining contributes information to withheld necessary sentence types, beyond unique-ID memorization. The learned relational operator is causally useful in matched ablations. Classical normalization/inference still dominates exact correctness and speed.

**Not established:** A universal representation rewrite principle; Qwen autonomously generating its own memory ontology; a learned mechanism directly rewriting Qwen's native hidden states or KV cache; improvement across independent tasks; learned choice of computation budget; transfer to larger language models; or superiority to exact classical algorithms.

The next stringent experiment must make **the representation and operator themselves reusable across at least two independently defined relational tasks**, include novel entity words/structure rather than only unseen complete strings from a fixed 150-item vocabulary, and learn state-dependent read/write inside Qwen's working computation with matched frozen/nonwritable controls. No support-line annotations, ground-truth transition programs or specially favorable synthetic grading should be injected. If no robust gain occurs, report it plainly rather than treating expressivity as an optimization guarantee.
