# Qwen3 mutable-state research — 2026-11-13 evidence ledger

## Executed, not proposed

Qwen3-0.6B official checkpoint was loaded locally on CPU after SHA-verified GitHub Actions sharded artifact transfer. Earlier static 8-slot KV compression/distillation did not preserve downstream next-token answers on six fact probes. This does not test a trained, task-adaptive editor.

### Countdown-4, exact Fraction verification
- Controller: trainable 96x96 numeric/action policy, three verified workspace rewrites per solution, trained using successful outcome-only rollouts. **Not** Qwen weight training, **not** learned unconstrained latent context.
- ID sample: 1,000 training solvable combinations (distinct 1..17), separate validation and 308 held-out. Beam32: trained **250/308**, untrained same-architecture **21/308**.
- OOD sample: 200 solvable problems with at least one number 18..22 (training used 1..17). Beam32: trained **172/200** versus untrained **4/200**; single trajectory trained **20/200**.
- Cost OOD 200 puzzles: neural beam32 3.733 seconds for 172/200; independent classical Fraction exact solver 0.448 seconds for 200/200 with caches reset. Classical dominates overall.
- Read-rewrite-read using Qwen final hidden state and an adapted head: ID 100 cases **10/100** with hidden vs **7/100** numeric-only; OOD 100 cases **7/100** with hidden vs **10/100** numeric-only. No reliable Qwen-specific gain.

### Official Facebook bAbI QA2 en-10k, answer-only learning
- Dataset: original 10k train questions/2000 stories, 1000 test questions/200 stories. Critical fix: validation splits must be by complete story, not by individual QA pairs (avoids history overlap leakage).
- Frozen Qwen3-0.6B sentence features; learned 128-D GRU update after each sentence; matched GRU trained on last-four-sentence context only. Training: 9000 examples, validation: 1000 examples (disjoint stories), official test: 1000.
- Test **441/1000** full-stream state vs **413/1000** last-four control. Paired wins 140 full-only vs 112 baseline-only; exact two-sided McNemar p=0.08877, so evidence not statistically decisive at p<0.05. Long stories >=20 facts: **99/269** vs **87/269**.
- Ablation on same full-stream trained model: last 8 events **447/1000**, full sequence **441/1000**, reverse event order **228/1000**. Current memory update has not shown robust long-history utilization. GRU recurrence is a known technique, not a novel free rewriting mechanism.
- Dataset retrieval workflow is on branch research/qwen3-streaming-memory-babi-20261113.

## Interpretation
In restricted arithmetic, a learned state-dependent EDIT policy improves held-out exact results, but a simple classical solver is more accurate/faster. Direct frozen Qwen KV mixing and hidden-conditioned action heads did not establish the intended gain. On independent bAbI, modest test advantage is not conclusive. Do NOT claim a general new reasoning mechanism from these.
