# Avatar Forge Hair — source provenance

This directory exists because generated artifacts are not sufficient provenance.

## Recovered lineage

- **v3**: first strand-groom generator attached to the real Avatar Forge `Head` joint.
- **v6**: last fully packaged pre-repository source snapshot. It added guide-local followers, collision projection, lock dynamics, candidate scoring, and 2D export.
- **v7–v10 experiments**: texture-continuum and material-state experiments were executed in the working environment; several generated GLBs/previews survived, but not every intermediate source file was retained independently. Treat this as a process defect, not an authoritative source lineage.
- **v11**: reconstructed forward from the v6 source snapshot plus the validated v7–v10 architectural findings. From v11 onward, Git is the authority.

## Repository policy

Commit source, tests, small configuration, documentation, and provenance. Do not commit large generated GLBs, render videos, cache files, or source avatar assets by default. They are reproducible outputs from a locally supplied Avatar Forge model.
